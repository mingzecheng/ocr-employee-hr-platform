### 已验收

- OCR 服务保留原始图片、OCR 原始结果和检测框 PNG 效果图。
- PNG 检测框效果图可通过 `GET /api/archive/ocr-bindings/{bindingId}/detection-preview` 经网关返回，响应类型为 `image/png`。
- OCR 文本块包含文字、置信度和坐标，员工档案类型可以返回姓名、员工编号等字段及字段校验状态。
- 同一档案版本重复触发 OCR 返回同一个 `taskId`，不会重复创建 OCR 任务。
- 员工列表使用 Redis cache-aside，key 格式为 `hr:list:archive:{sha256}`，TTL 为 60 秒；缓存内容为脱敏 DTO，空列表也会缓存。
- Gateway 登录、员工列表、图片上传、OCR 结果和检测框预览链路通过 JWT 验证。
- Workflow 人事流程闭环通过网关完成：草稿、提交、部门审批、HR 审批和 `APPROVED` 最终查询；审批历史和审计日志写入 `workflow_db`。
- 档案访问使用闭环通过网关完成：访问申请草稿、部门审批、人事复核、领取、异常归还和 `ABNORMAL` 最终查询；V2 迁移新增申请、材料范围、访问审批和使用记录表。
- Vue 管理端登录、员工列表、档案上传、OCR 结果、字段置信度、字段修订、检测框预览和下载状态已通过浏览器链路验证。

## 2026-09-18 档案资源工作台实现

### 已实现

- archive-service 新增员工材料列表、材料版本历史和原图受控下载接口：
  - `GET /api/archive/employees/{employeeId}/documents`
  - `GET /api/archive/documents/{documentId}/versions`
  - `GET /api/archive/versions/{versionId}/download`
- 材料和版本查询通过 `archive_record -> employee` 关联并应用 `DataScope`；下载在 scope 校验通过后才访问 MinIO，不接受客户端传入 object key。
- 原图下载响应保留数据库中的媒体类型和安全文件名，使用 `Content-Disposition: inline`；越权统一返回 `403/FORBIDDEN`。
- Vue 员工档案页增加材料目录、按需版本展开、原图 blob 预览和下载；切换文件或组件卸载时释放 blob URL。
- OCR 检测框效果图仍作为独立证据保留；原始影像、OCR 文本块和检测框可以分别使用，不因效果图缺失而隐藏识别结果。
